# Resume / Candidate Screening System

## Project Overview
An automated machine learning screening system that parses resumes, extracts relevant skills, calculates candidate-to-job fit scores using TF-IDF and Cosine Similarity, and identifies missing skills.

## Features
- Resume text cleaning and normalization
- Skill extraction and matching against job descriptions
- Candidate ranking based on role fit score
- Skill gap identification
